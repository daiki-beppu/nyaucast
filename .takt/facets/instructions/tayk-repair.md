診断レポートを、この修正タスクの計画として扱ってください。

## 手順

1. 診断の因果連鎖で断つと決めた箇所を確認する
2. 診断に記録された要件 ID を維持し、未宣言の変更を混ぜない
3. 原因を除き、再現テストを削除、skip、期待値緩和せず red から green にする
4. 修正方針が ADR と衝突する場合は修正せず再診断へ返す
5. 全差分を確認し、因果関係のない変更を残さない
6. 完了前に、CI と同一の検査ゲートを通す:
   ```
   bun run check
   ```

対症療法の自己検査:

- 原因を残したまま手前に guard、early return、try-catch を足しただけではないか
- 想定外の値を弾いただけで、その値が来る原因を残していないか
- テストは green でも診断の因果連鎖が一段も変わっていないのではないか

いずれかに該当する場合は変更を完成扱いにせず、再診断へ返してください。
