# 公開ゲートの前: ショートの推奨 → 投稿案

入口は [SKILL.md](../SKILL.md)。失敗したら [failures.md](failures.md)。

前提: 企画ゲートが承認されていて、公開ゲートはまだ承認していない（公開ゲートの承認の後に投稿案を書き直しても、生きている投稿がある間は効かない。投稿を取り消してから書き直し、再承認を頼む。[publish.md](publish.md)）。ここで使う tool は、企画ゲートの承認の前は `ProduceGateNotApproved` で失敗する。

## 1. ショートの候補の推奨

候補ごとに `video_recommend_short_cut` を呼ぶ。`cut`（`clip` = 切り抜き、`dedicated` = 専用、`none` = どちらも出さない）、`number`（候補の番号）、`videoId`。

- 人間が公開ゲートで、候補ごとの最後の推奨を既定の選択として見る。人間がその場で選び直せる。
- append-only で、最後の推奨が有効。同じ推奨を書き直しても何も積まない。
- 候補が 0 件の動画は、この手順を省いて投稿案（長尺だけ）に進める。

## 2. 投稿案を書く

カット（長尺、または採用するショートの候補）ごと・SNS ごとに `video_write_post_draft` を呼ぶ。`post`（投稿文）、`scheduledAt`（投稿時刻）、`short`（ショートの候補の番号。長尺は省く）、`videoId`。

### SNS ごとの投稿文の形と上限

| SNS       | 投稿文の形                       | 上限                                                                                                                   |
| --------- | -------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| YouTube   | タイトルと説明（タグは持たない） | タイトル 100 文字以内、説明 5000 バイト（UTF-8）以内                                                                   |
| Instagram | 本文                             | 2200 文字以内                                                                                                          |
| X         | 本文                             | 280（X の重み付きの長さ。和文・絵文字は 2）以内。URL を含められない（裸のドメイン例: example.com も URL として数える） |

投稿文が空、上限を超える、X に URL を含むときは `InvalidPostText`（`platform`・`field`・`rule`）で拒否され、何も書かれない。

### 投稿時刻

`scheduledAt` は時差付きの ISO 8601（`Z` または `±hh:mm`）で書く。時差の無い時刻は受け付けない。

- **YouTube**: 予定時刻で YouTube 側に予約する（private で upload し、`publishAt` を予定時刻にする）。予定時刻を過ぎると、予約済みの upload が無ければ nyaucast は upload しない。
- **Instagram・X**: nyaucast が予定時刻に（チャンネル設定の許容時間の間に）即時投稿する。SNS 側の予約機能は使わない。

### AI 生成の開示

YouTube・Instagram・X のいずれでも、投稿を送る仕組みが AI 生成であることを常に示す。投稿文にその文言を書く必要は無く、agent がこれを外せる引数・設定・分岐も無い。

### 長尺の YouTube の説明の出典 URL

長尺（`short` を省いた）の YouTube の投稿の説明には、企画の出典の URL（`video_status` の `plan.sources` にある URL）を必ず書く。ショートや、Instagram・X の投稿文にはこの義務は無い（X は本文に URL を書けない）。

### 投稿案の鮮度・冪等性

投稿案は append-only で、キー（候補・SNS・アカウント）ごとに最後の版が有効。同じ投稿文・同じ投稿時刻を書き直しても何も積まない。ショートの投稿案は、その候補の最後の版より新しいときだけ公開ゲートで数えられる（候補を書き直した後は、投稿案も書き直す）。

## 3. 公開ゲートの前

投稿案とショートの推奨が揃ったら [publish.md](publish.md) に進み、人間に公開ゲートの承認を頼む。
