# 確認待ちの理由・失敗のタグ → 手順

tool と CLI は、確認待ちの理由と失敗を安定した識別子（型付きのエラーのタグ、または `video_status` の `reason`）と事実で返す。「次に取る行動」は返さない。この表が、識別子から手順への対応を持つ。入口は [SKILL.md](../SKILL.md)。

戻し方は次の組み合わせで決まる。専用の resume や rollback は無い。

- **人間に各 SNS の画面で確かめてもらう**（YouTube は Studio、Instagram・X はアプリ・Web の画面）。
- **投稿を取り消す**: 人間に `nyaucast post cancel <post-id>` を頼む。
- **今すぐ実行する**: 人間に `nyaucast post run-now <post-id>` を頼む。
- **公開済みとして記録する**: 人間に `nyaucast post mark-published <post-id> <url>` を頼む。
- **書き直して再承認する**: [drafts.md](drafts.md) で投稿案を書き直し、人間に `nyaucast video publish <id>` を頼む。
- **人間に設定・宣言・認証を直してもらう**: 直り次第、同じ操作をやり直す。

人間に頼む操作は、agent が自分で行わず、何を直してほしいかを事実とともに伝える。

## 確認待ちの理由（`video_status` の `posts` の `reason`）

| 理由                      | 事実                                                                                               | 手順                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------- | -------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `upload_rejected`         | 公開の確認の照会で、SNS が upload を拒否した                                                       | 人間に Studio で確かめてもらう。公開されていれば `nyaucast post mark-published`、出し直すなら `nyaucast post cancel` → 投稿案を書き直す → `nyaucast video publish`                                                                                                                                                                                                                           |
| `upload_failed`           | 公開の確認の照会で、SNS 側の処理が失敗した                                                         | 同上                                                                                                                                                                                                                                                                                                                                                                                         |
| `resultless_attempt`      | 開始したが結果の無い試行。自動では再実行しない                                                     | 人間に各 SNS の画面（YouTube は Studio）で、実際に公開されているか確かめてもらう。公開されていれば `nyaucast post mark-published`。公開されていなければ（非公開のままの動画が残っている場合を含む）`nyaucast post cancel`（リモートの ID が分からないので SNS 側は消せない。残っている非公開の動画は人間に SNS の画面で消してもらう）→ 投稿案を書き直す → `nyaucast video publish`           |
| `publication_unconfirmed` | upload は成功したが、予定時刻と許容時間の内に公開の確認が取れない                                  | 人間に Studio で確かめてもらう。公開済みなら `nyaucast post mark-published`、そうでなければ `nyaucast post cancel` → 投稿案を書き直す → `nyaucast video publish`                                                                                                                                                                                                                             |
| `account_mismatch`        | 投稿に保存したアカウント ID と、宣言・認証したトークンの ID のどれかが食い違う                     | 人間に `config/channel/accounts.json` の宣言をこの投稿のアカウント ID へ戻し、必要なら`nyaucast auth <channel> <platform>` でそのアカウントとして認証し直してもらう（`nyaucast auth status` で状態が見える）。直れば時刻の判定に戻る。投稿案を書き直しても投稿に保存済みのアカウント ID は変わらないため、別アカウントでの書き直しでは解消しない。`nyaucast post run-now` でも照合は外れない |
| `stale_facts`             | 公開ゲートの承認より後にカットを描き直した、サムネイルを選び直した、または書き出しのファイルが無い | `nyaucast post cancel` →（必要なら描き直し・選び直し）→ 投稿案を書き直す → `nyaucast video publish` で承認を事実より新しくする。描き直すだけでは解けない                                                                                                                                                                                                                                     |
| `tolerance_exceeded`      | 予定時刻からの遅れが許容時間を超えた。YouTube は予定時刻を過ぎた時点                               | Instagram・X は、出してよければ人間に `nyaucast post run-now` を頼む。YouTube は private で upload すると即時公開になるため今すぐ実行では出せず、`nyaucast post cancel` → 未来の時刻で投稿案を書き直す → `nyaucast video publish`。この理由では `nyaucast post mark-published` は通らない                                                                                                    |

## 公開ゲートの拒否のタグ

| タグ                                             | 意味と手順                                                                                                                                                                                                                                                                                                         |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `StdinNotTerminal`                               | agent が `nyaucast video publish` を叩いた（TTY が無い）。人間に叩いてもらうコマンドを組み立てて渡す                                                                                                                                                                                                               |
| `PublishFactsChanged`                            | 承認の対話中に表示した事実（投稿案・カット・サムネイル）が変わった。頭から `nyaucast video publish` を頼み直す                                                                                                                                                                                                     |
| `NoPostToCreate`                                 | 作る投稿が 1 件も無い（候補をすべて「どちらも出さない」にしたなど）。投稿案か推奨を見直す                                                                                                                                                                                                                          |
| `AccountNotDeclared`                             | 対象の SNS にアカウントの宣言が無い。人間に `config/channel/accounts.json` を直してもらう                                                                                                                                                                                                                          |
| `AccountsDeclarationInvalid`                     | アカウントの宣言ファイルが壊れている。人間に直してもらう                                                                                                                                                                                                                                                           |
| `AccountNotAuthenticated`                        | 宣言はあるが認証していない。人間に `nyaucast auth <channel> <platform>` を頼む                                                                                                                                                                                                                                     |
| `AccountIdMismatch`                              | 認証したトークンの ID が宣言と食い違う。人間に認証し直してもらう                                                                                                                                                                                                                                                   |
| `DraftAccountNotDeclared`                        | 承認待ちの投稿案に書いたアカウントが、現在の宣言と違う。人間に宣言をその投稿案のアカウントへ戻してもらい、必要なら `nyaucast auth <channel> <platform>` で同じアカウントとして認証し直してもらう。投稿案は書き直しても append されるだけでアカウントごとに残り、投稿先のアカウントを書き直しで変えることはできない |
| `ScheduledInPast`                                | 表示した投稿案の予定時刻がすでに過去。[drafts.md](drafts.md) で未来の時刻に書き直す                                                                                                                                                                                                                                |
| `AdoptedCutHasNoDraft`                           | 採用したカット（長尺、または選んだショートの切り抜き・専用）に投稿案が無い。[drafts.md](drafts.md) で書く                                                                                                                                                                                                          |
| `InvalidPostText`                                | 投稿文が検査に落ちた（`field`・`rule`）。[drafts.md](drafts.md) の上限・禁止を直して書き直す                                                                                                                                                                                                                       |
| `ChannelConfigNotFound` / `InvalidChannelConfig` | チャンネルの設定が無い、または形が不正。人間に直してもらう                                                                                                                                                                                                                                                         |
| `VideoNotFound`                                  | 動画の ID が違う。ID を確かめて呼び直す                                                                                                                                                                                                                                                                            |
| `ProduceGateNotApproved`                         | 企画ゲートが承認されていない。`explainer-lifecycle` codec の企画ゲートの手順に従う                                                                                                                                                                                                                                 |

| タグ                                             | 意味と手順                                                                                            |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| `InvalidPostText`                                | 投稿文が検査に落ちた。上限・空・X の URL を直して `video_write_post_draft` を書き直す                 |
| `AccountNotDeclared`                             | 対象の SNS にアカウントの宣言が無い。人間に `config/channel/accounts.json` を直してもらう             |
| `AccountsDeclarationInvalid`                     | アカウントの宣言ファイルが壊れている。人間に直してもらう                                              |
| `ShortCandidateNotFound`                         | 指定したショートの候補が無い、または取り下げられている。`video_status` の `shorts` を確かめて呼び直す |
| `ProduceGateNotApproved`                         | 企画ゲートが承認されていない。`explainer-lifecycle` codec の企画ゲートの手順に従う                    |
| `VideoNotFound`                                  | 動画の ID が違う。ID を確かめて呼び直す                                                               |
| `ChannelConfigNotFound` / `InvalidChannelConfig` | チャンネルの設定が無い、または形が不正。人間に直してもらう                                            |

## 投稿の実行で出る失敗のタグ（一時的・恒久的）

`nyaucast post run` と `nyaucast post run-now` が共有する実行の経路で出る。一時的な失敗は、時間をおけば次の実行で成功しうる（通信の途中で切れた、処理の完了を待ち切れなかった）。恒久的な失敗のうち、認証・権限が原因のものは、そのアカウントの残りの投稿を**同じ実行の中では試さない**。それ以外の一時的・恒久的な失敗は、そのアカウントの他の投稿も同じ実行の中で試す。

| 分類                                     | タグ                                                                                                                                                                                                                                                                                              | 手順                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 一時的（アカウントは止めない）           | `InstagramBoundaryFailed`・`InstagramContainerNotReady`・`XHttpBoundaryFailed`・`XMediaProcessingUnfinished`・`YouTubeHttpBoundaryFailed`・`R2BoundaryFailed`                                                                                                                                     | 時間をおいて `video_status` の `posts` を読む。`status` が `due` なら `nyaucast post run` で再試行する（`nyaucast post run-now` は `due` を拒否する）。確認待ちなら `reason` を上の対応表で引き、理由ごとの手順を人間に渡す。繰り返すなら人間に伝える                                                                                                                                                                                                                                                                                                       |
| 恒久的（アカウントは止めない）           | `ChunkReadFailed`・`InstagramContainerFailed`・`InstagramResponseInvalid`・`InvalidPostText`・`ResumableUploadFailed`・`ThumbnailReadFailed`・`UntrustedYouTubeUrl`・`XMediaProcessingFailed`・`XResponseInvalid`・`YouTubeResponseInvalid`・`YouTubeResendDeadlinePassed`・`R2PayloadReadFailed` | 事実を人間に伝える。投稿文・ファイルが原因なら [drafts.md](drafts.md) で直してから、人間に `nyaucast post cancel` → 書き直し → `nyaucast video publish` を頼む                                                                                                                                                                                                                                                                                                                                                                                              |
| 応答の status・code 次第                 | `InstagramHttpFailure`・`R2HttpFailure`・`XHttpFailure`・`YouTubeHttpFailure`                                                                                                                                                                                                                     | `InstagramHttpFailure` は本文のエラーコードを先に見る: code 4・17・613（レート制限）は status に関わらず一時的、code 190（認証エラー）は status に関わらず恒久的でアカウントを止める（下の行）。コードが無い、またはこの 3 種のどれでもないときは、他の 3 タグと同じ status の規則に落ちる: 429・5xx・quota 超過の 403 は一時的（上の一時的と同じ手順）。401 は恒久的で、かつそのアカウントを止める（下の行）。それ以外の status は恒久的でアカウントは止めない（上の恒久的と同じ手順）                                                                     |
| 恒久的・アカウントを同じ実行の中で止める | 上の行で「アカウントを止める」とした場合（`InstagramHttpFailure` の code 190、または上の規則で status 401 に落ちた場合）と、認証・シークレットの更新そのものの失敗（上のどのタグにも当たらない残り。`ChunkReadFailed` 等の恒久的だが止めないタグは含まない）                                      | そのアカウントの残りの投稿（この実行でまだ試していない投稿）は、同じ実行の中では試されない。宣言・認証が直っていれば、次回の `nyaucast post run` で自動的に再開する。**失敗したこの投稿自体**は `status` が `failed` になり、`nyaucast post run` の対象（`due`）には二度と戻らない。人間に認証（`nyaucast auth <channel> <platform>`）やシークレットの設定を直してもらい、直り次第、人間に `nyaucast post run-now <post-id>` を頼む。投稿案も直す必要があれば、`nyaucast post cancel` → [drafts.md](drafts.md) で書き直し → `nyaucast video publish` を頼む |

`nyaucast post run-now` だけが返す失敗:

| タグ              | 意味と手順                                                                                                                                                 |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PostNotRunnable` | 今すぐ実行の対象ではない投稿（`due`・`reserved`・`scheduled`・`canceled`・`published`）に `nyaucast post run-now` を叩いた。対象は確認待ちか失敗の投稿だけ |

`nyaucast post mark-published` だけが返す失敗:

| タグ                | 意味と手順                                                                                                                                          |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PostNotRecordable` | 公開済みの記録の対象ではない投稿に叩いた。対象は `resultless_attempt`・`publication_unconfirmed`・`upload_rejected`・`upload_failed` の確認待ちだけ |

## 失敗のタグが無い失敗

`nyaucast post run` の 1 行は、タグの無い事実（投稿が確認待ちになった、アカウントを止めた、投稿案が足りない、など）も返す。この場合は `video_status` の `posts` で状態（`status`）と、確認待ちなら理由（`reason`）を読み、上の対応表に従う。CLI の引数の誤りは、使い方とエラーが出力される。コマンドの形を直して人間に伝え直す。
