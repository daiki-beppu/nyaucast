# 失敗のタグ → 手順

tool と CLI は、失敗を安定した識別子（型付きのエラーのタグ）と事実で返す。「次に取る行動」は返さない。この表が、タグから手順への対応を持つ。入口は [SKILL.md](../SKILL.md)。

戻し方は 3 つの組み合わせだけ。専用の resume や rollback は無い。

- **頭から歩き直す**: 原因を直したあと、失敗した tool を同じ入力で呼び直す（またはその区間の頭から順に呼び直す）。冪等なので、できているものはすぐに返り、足りない分だけが作られる。課金された外部呼び出しは、途中で落ちても成果物と事実が残り、同じ回を払い直さない。
- **`force`**: 決定的な出力を意図して作り直す。
- **やめる**: 人間に `nyaucast video abandon <id>` を頼み、新しい動画を作る。

人間に頼む操作（設定・シークレット・ログイン・ゲートの承認・サムネイルの選択）は、agent が自分で行わず、何を直してほしいかを事実とともに伝える。直してもらったら、頭から歩き直す。

## 動画とゲート

| タグ                         | 意味と手順                                                                                                                                                                                         |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `VideoNotFound`              | 動画の ID が違う。ID は `explainer_write_plan` が返したもの。取り違えを直して頭から歩き直す。ID を失ったときは、題材を変えずに `explainer_write_plan` を呼ぶと既存の動画が `created: false` で返る |
| `VideoIdCollision`           | 動画の ID の生成が衝突した。`explainer_write_plan` を呼び直す                                                                                                                                      |
| `PlanAlreadyApproved`        | 企画ゲートの承認の後は企画を書き換えられない。企画を変えたいなら、やめて新しい動画を作る                                                                                                           |
| `VideoAbandoned`             | やめた動画の企画は書き換えられない。続けたいなら人間に `nyaucast video produce <id>` で承認し直してもらう。作り直すなら、別の題材で新しい動画を作る                                                |
| `ProduceGateNotApproved`     | 企画ゲートが承認されていない。plan 区間を終え、SKILL.md の「企画ゲート」に従って人間に判断を頼む。承認されたら頭から歩き直す                                                                       |
| `ThumbnailSelectionRequired` | 企画の最後の更新より新しいサムネイルの選択が無い（`nyaucast video produce` の失敗）。人間に `nyaucast video thumbnail` でサムネイルを選び直してもらい、承認し直す                                  |
| `VideoPublishApproved`       | 公開ゲートを承認した動画はやめられない（`nyaucast video abandon` の失敗）。配信を止めるときは投稿単位で取り消す。この codec の範囲の外                                                             |

## チャンネルの設定（人間が直す）

| タグ                        | 意味と手順                                                                                                             |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `ChannelConfigNotFound`     | チャンネルの設定ファイルが無い。人間に作ってもらい、頭から歩き直す                                                     |
| `InvalidChannelConfig`      | 設定ファイルの形が不正。人間に直してもらい、頭から歩き直す                                                             |
| `NotExplainerChannel`       | 動画の種類が解説動画のチャンネルではない。作業しているディレクトリがそのチャンネルのルートか確かめ、違えば人間に伝える |
| `ThemeNotDeclared`          | チャンネルにテーマ（色・大きさ・フォント）の宣言が無い。人間に宣言してもらい、頭から歩き直す                           |
| `VoiceNotDeclared`          | チャンネルにボイスの宣言が無い。人間に宣言してもらい、頭から歩き直す                                                   |
| `ThumbnailTypeNotDeclared`  | チャンネルにサムネイルの型の宣言が無い。人間に宣言してもらい、頭から歩き直す                                           |
| `UndeclaredHitPattern`      | 宣言していない当たる型を指定した。`explainer_fetch_topic_candidates` の `hitPatterns` のキーから選び直して書き直す     |
| `FontNotFound`              | テーマが指すフォントファイルが無い。人間にファイルを置いてもらい、頭から歩き直す                                       |
| `FontUnsupported`           | テーマが指すフォントファイルを使えない形式。人間に直してもらい、頭から歩き直す                                         |
| `ReferenceImageNotFound`    | サムネイルの型が指す参照画像が無い。人間に置いてもらい、頭から歩き直す                                                 |
| `ReferenceImageUnsupported` | 参照画像の形式を使えない。人間に直してもらい、頭から歩き直す                                                           |

## 環境・シークレット・外部サービス

| タグ                       | 意味と手順                                                                                                         |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `SecretNotConfigured`      | 必要なシークレットが設定されていない。人間に設定してもらい、頭から歩き直す                                         |
| `SecretResolutionFailed`   | シークレットを読み出せなかった。人間に確かめてもらい、頭から歩き直す                                               |
| `GeminiHttpFailure`        | 外部 API が失敗を返した。時間をおいて頭から歩き直す（合成・生成済みの分は再利用される）。繰り返すなら人間に伝える  |
| `GeminiResponseInvalid`    | 外部 API の応答が読めなかった。頭から歩き直す。繰り返すなら人間に伝える                                            |
| `GeminiHttpBoundaryFailed` | 外部 API への通信自体が失敗した。ネットワークを確かめ、頭から歩き直す。繰り返すなら人間に伝える                    |
| `CodexNotLoggedIn`         | 画像生成に使う codex にログインしていない（画像は 1 枚も生成していない）。人間にログインしてもらい、頭から歩き直す |
| `CodexUnavailable`         | codex を使えない。人間に導入を頼む。直ったら頭から歩き直す                                                         |
| `CodexExecFailed`          | codex の実行が失敗した。頭から歩き直す。繰り返すなら人間に伝える                                                   |
| `CodexImageMissing`        | codex が画像を出さなかった。頭から歩き直す。繰り返すなら人間に伝える                                               |
| `ChromeUnavailable`        | ブラウザを取得・起動・操作できない（描画とプレビュー）。ネットワークと環境を人間に確かめてもらい、頭から歩き直す   |

## サムネイル

| タグ                         | 意味と手順                                                                                                                                                                                                                                           |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `BannedThumbnailWords`       | `text` か `background` に禁止語がある（外部呼び出しの前に止まる）。禁止語を避けて書き直す                                                                                                                                                            |
| `ThumbnailImageRejected`     | 生成した画像が検査に落ちた（理由は `unreadable` / `too_small` / `not_16_9` / `too_large`）。落ちた番号は作った扱いで、再実行しても作り直さない。他の番号は残る。良い候補が足りなければ、`text` と `background` を直して `force` つきで新しい回を作る |
| `ThumbnailCandidateNotFound` | 指定した回と番号の候補が無い。`video_status` の `thumbnails` で実在する候補を確かめて呼び直す                                                                                                                                                        |
| `ThumbnailCandidateExcluded` | 除外した候補は選べない（`nyaucast video thumbnail` の失敗）。別の候補を人間に選んでもらう                                                                                                                                                            |
| `InvalidThumbnailCandidate`  | 候補の指定が `<回>-<番号>` の形ではない（`nyaucast video thumbnail` の失敗）。形を直して人間に伝え直す                                                                                                                                               |
| `ThumbnailChoiceRequired`    | 候補の指定も `--file` も無い（`nyaucast video thumbnail` の失敗）。どちらか 1 つを指定して人間に伝え直す                                                                                                                                             |

## 台本・ショートの候補・図解（agent の入力を書き直す）

| タグ                     | 意味と手順                                                                                                                                                                                                                                                 |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `InvalidReadingMarkup`   | 読み仮名の記法の誤り（閉じ忘れ・入れ子・読みが 2 つ・空）。位置（シーンと段落）を直して `explainer_write_script`（専用ショートなら `explainer_write_short`）を書き直す。保存済みの台本が今の検査に通らないとき（他の tool の失敗）も、台本を直して書き直す |
| `ParagraphTooLong`       | 1 段落の読みが長すぎる。段落を分けて台本を書き直す。保存済みの台本が今の検査に通らないときも同じ                                                                                                                                                           |
| `ScriptNotFound`         | 台本が無い。`explainer_write_script`（専用ショートなら `explainer_write_short`）を先に呼び、頭から歩き直す                                                                                                                                                 |
| `InvalidScriptFile`      | 保存済みの台本が読めない形。台本を書き直し、頭から歩き直す                                                                                                                                                                                                 |
| `SceneNotFound`          | 台本に無いシーン番号の図解を書こうとした。台本のシーンの数を確かめ、番号を直す                                                                                                                                                                             |
| `InvalidDiagrams`        | 図解の違反（シーンと規則が列挙される）。すべての違反を直して、そのシーンの図解を書き直す。台本のシーンに図解が無いのも違反。composition を組むときの全体検査でも出る                                                                                       |
| `ShortCandidateNotFound` | 指定した番号のショートの候補が無い、または取り下げた。`video_status` の `shorts` を確かめる。使うなら `explainer_write_short` で書く（取り下げた候補は書き直すと戻る）。使わないなら、そのカットを作らない                                                 |
| `InvalidShortRange`      | 切り抜きの範囲が逆、または長尺の台本（タイミング表）に無い段落を指している。長尺の台本を変えた後に起きる。範囲を直して `explainer_write_short` を書き直し、頭から歩き直す                                                                                  |
| `ShortTooLong`           | ショートが 60 秒を超える。切り抜きは範囲を狭め、専用ショートは台本を短くして `explainer_write_short` を書き直し、音声から頭から歩き直す                                                                                                                    |
| `NarrationTooLong`       | 4 回合成しても段落の音声が長すぎる。その段落（シーンと段落が示される）を短く、または分けて台本を書き直し、`explainer_synthesize_narration` から頭から歩き直す                                                                                              |

| `BgmSongNotInPool`     | 指定した曲がプールに無い。プールにある曲を指定するか、`song` を省く                                                                                            |

| `BgmSongUnreadable`    | 曲のファイルを読めない。人間に確かめてもらい、頭から歩き直す                                                                                                   |
| `BgmLoopTooShort`      | 曲からループを作れない（短すぎる）。別の曲を `song` で指定するか、人間に宣言を直してもらう                                                                     |
| `BgmLoopOutOfRange`    | 曲のループ位置が範囲外。別の曲を `song` で指定するか、人間に宣言を直してもらう                                                                                 |

## 描画

| タグ                          | 意味と手順                                                                                                                                                                         |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `CompositionNotFound`         | composition が無い。`explainer_assemble_composition` を先に呼び、頭から歩き直す                                                                                                    |
| `InvalidComposition`          | composition が契約を破っている（違反が列挙される）。図解を直して `explainer_assemble_composition` を `force` つきで呼び、描画から歩き直す                                          |
| `NondeterministicComposition` | 時刻で絵が決まらない（同じ時刻に飛んでも同じ絵にならない。違う時刻が列挙される）。図解を見直して書き直し、`explainer_assemble_composition` を `force` つきで呼び、描画から歩き直す |
| `AudioTrackNotFound`          | 最終の音声トラックが無い。`explainer_mix_audio_track` を先に呼び、頭から歩き直す                                                                                                   |
| `AudioTrackUnreadable`        | 最終の音声トラックを読めない。`explainer_mix_audio_track` を `force` つきで呼び直し、描画から歩き直す                                                                              |
| `EncodeFailed`                | エンコードが途中で失敗した（何も書かれない）。`explainer_render_cut` を呼び直す。繰り返すなら人間に伝える                                                                          |

## 失敗のタグが無い失敗

CLI の引数の誤りは、使い方とエラーが出力される。コマンドの形を直して人間に伝え直す。想定外の失敗（タグが出ない失敗）は、事実をそのまま人間に伝え、推測で回避しない。
