# 企画オリジナリティポリシー

旧 SKILL.md「オリジナリティ保証ルール」＋「OK / NG 例」の移設先。
TTP（転写）と複製の境界を判定する。

## 原則

| 原則 | 基準 |
|---|---|
| 転写するのは型 | 構造・パターン・型・欲求訴求の構造。タイトル・シリーズ名・表現そのものではない |
| 根拠の明記 | 全候補に転写元（競合名 + 当たり動画または勝ちパターン）を書く |
| 再現性 | 1 回きりの表面模写（画像・フレーズの直接コピー）は転写基準を満たさない |

## 判定

| 候補の状態 | 判定 |
|---|---|
| 競合のタイトルをほぼそのまま使っている | REJECT |
| 競合のシリーズ名を流用している | REJECT |
| 転写元が書かれていない | REJECT |
| 既存 collection と類似度が閾値を超えている | 警告（人間の選択材料として提示する） |
| 具体的な場所 + 天候/時間帯 + ムードで情景が浮かぶ | OK |
| 抽象的で情景がない（`Relaxing Music` / `Beautiful Night Music` / `BGM Collection` 等） | REJECT |
| 転写元の型を使い、タイトル・訴求は自チャンネルの語彙で書き直している | OK |
