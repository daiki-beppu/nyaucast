# 企画候補の型

旧 SKILL.md「ペルソナベース企画フレームワーク」「企画ルール」「オブジェクトデザインルール」の移設先。

## ペルソナの扱い

企画候補は**第一ペルソナ 1 人**に絞って生成する。複数ペルソナをローテーションしない。
幅は「同じ人物の別シーン・別感情・別利用文脈」（非転写モード）または
「別々の当たり動画」（転写モード）から出す。

## 候補が持つべき項目

| 項目 | 内容 |
|---|---|
| ターゲットペルソナ | 名前・視聴シーン・ユースケース |
| 転写元 | 競合チャンネル名 + 当たり動画または勝ちパターン |
| 転写する型 | タイトル構造 / テーマ構造 / 利用シーン |
| 参照元が満たす欲求 | 欲求語彙 + ソース + 根拠 |
| 欲求整合 | タイトル・サムネ・楽曲が同じ欲求を満たす根拠 |
| 情景没入スコア | サムネ + タイトルで情景が浮かぶ度合い（高 / 中 / 低） |
| オブジェクト定義 | 差し替えスロットの具体値（名前・ストーリー・ビジュアル） |

## オブジェクトデザインの原則

- 名前は短く詩的に
- ストーリーは「誰が、どんな場面で、なぜ」を描写する
- ビジュアルは形状・色・質感まで具体的に指定する
- 転写モードでは差別化軸から値を作らず、転写元の当たり動画に基づいて定義する

## タイトル

チャンネル設定のタイトルテンプレートに従う。世界観（core message / ジャンル）と一貫させる。
