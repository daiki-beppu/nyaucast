企画立案に必要な入力を tayk MCP tool から集め、構造化出力にまとめてください。

**やること:**

1. `collection_plan_inputs` を呼び、入力モード・転写モード・当たり動画件数・候補数を受け取る
2. `benchmark_list` を呼び、当たり動画とその勝ちパターンを受け取る
3. 入力モードが analytics のときだけ `analytics_latest` を呼び、戦略提案・次期候補・戦略ディスカッションを受け取る
4. `insights_open` を呼び、未消費の学びがあれば受け取る（0 件でも続行する）

**やらないこと:**

- 入力モード・転写モードを**自分で判定しない**。tool が返した値をそのまま構造化出力へ転写する
- 鮮度判定・データ整合の検査をしない。tool が事前条件で throw する
- tool がエラーを返した場合、回避策を試さずそのまま報告して止まる

**構造化出力:**

`input_mode` / `ttp_mode` / `hit_video_count` / `candidate_count` は tool の返り値をそのまま入れる。
この 4 つは遷移の決定に使われるため、推測・丸め・補完をしてはならない。

**報告:**

集まった材料の要約と、集まらなかった入力があればその名前と理由を書いてください。
